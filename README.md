# 📈 Chart Analyst Bot

Бот, который принимает скриншот графика и возвращает структурированный разбор:
**тренд → уровни → паттерны → сигнал (вход / стоп / тейки) → размер позиции → риски**,
плюс ведёт **журнал сделок со статистикой**.

Работает целиком на **Cloudflare Workers + Workers AI (vision)** — без серверов, без внешних платных API.

```
скриншот ──▶ Workers AI (llama-4-scout, vision) ──▶ строгий JSON ──▶ расчёт позиции ──▶ UI
                                                                          └────▶ KV (журнал)
```
